# 스파르타 부트캠프 챕터 3 - 1번 과제

## 퍼즐 오브젝트 설계

`Tick` 또는 `Timer`를 활용하여 퍼즐 오브젝트의 동작을 구현했습니다.

### `RotatingActor`
- 각 회전 축에 지정된 속도로 계속 회전하는 오브젝트입니다.
- `FRotator` 값을 사용해 회전 축과 회전 속도를 설정할 수 있습니다.

### `MovingPlatformActor`
- 시작 지점과 종료 지점을 지정된 이동 속도로 왕복 이동하는 오브젝트입니다.
- 시작/종료 위치를 나타내는 `SceneComponent`를 사용하여, 액터가 아닌 `StaticMesh`를 이동시키는 퍼즐 오브젝트입니다.
- `SceneComponent`를 사용하면 뷰포트에서 시작/종료 위치를 직관적으로 배치하고 편하게 수정할 수 있으며, 위치를 수정하면 실시간으로 바로 반영됩니다.

### `BlinkActor`
- 요구사항인 회전/이동 액터 외에, 일정 주기마다 사라졌다가 등장하는 오브젝트입니다.
- 시작 상태(표시/숨김), 초기 대기 시간, 표시/숨김 시간을 지정할 수 있어 원하는 동작으로 수정 가능합니다.
- `Timer`를 사용해 표시/숨김 상태를 반복합니다.

## 랜덤 소환 시스템
`GameMode`를 사용하여 게임 시작 시 오브젝트를 랜덤하게 소환합니다.

### 소환 개수 및 종류 설정
- `SpawnCount`와 `SpawnClassArray`를 설정하여 게임 시작 시 소환할 오브젝트의 개수와 종류를 지정합니다.

### 초기 값 설정
- 소환된 오브젝트는 `Initialize()`를 통해 속도, 이동 범위, 회전 속도 등 초기 값이 설정됩니다.
- `SpawnActor`로 생성한 뒤 `Cast<>`를 사용해 실제 타입을 확인하고, 각 액터에 맞는 `Initialize()`를 호출합니다.

## 시연 영상

각 퍼즐 오브젝트의 작동 모습을 확인할 수 있으며, `Details` 패널에서 값을 수정하면 즉시 동작에 반영됩니다.
